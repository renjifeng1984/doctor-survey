1. 产品定位

一个微信小程序，医生在里面完成：收到调研 → 作答 → 查结果 → 反馈。

不做招募页、不做签署、不做付款。

2. 为什么是移动端

医生不在电脑前。原有的摩擦——10 分钟失效链接、要手动刷新看状态、归档文件在微信打不开——本质是把 PC 交互搬到了手机上。

移动原生带来三件事：免登录、可主动提醒、可断点续做。

3. 本期服务对象

CC 在企微里沟通过、被告知"去小程序完成调研"的医生。

完整的前情是两句对话：CC 先说"这次调研麻烦你在小程序里填一下"，然后发一张小程序卡片。医生点开 → 登录 → 填完。

这说明三件事：

  • 入口是通用卡片：同一个项目一张卡，不区分人；
  • 身份靠登录：沿用小程序已有的登录方式，卡片不携带任何个人参数；
  • 落点是调研模块：不是首页，减少一次"再找一遍"。

4. 入口链路

一条链，五步：

CC 告知 → 发小程序卡片 → 点开 → 登录 → 进入调研

  1. 告知：CC 在既有企微会话里说明这次调研（为什么找他、多久、给什么）。
  2. 发卡片：一张指向调研模块的小程序卡片，path 固定为调研模块页。
  3. 点开：微信拉起小程序，直接落到调研模块。
  4. 登录：未登录走小程序已有的登录页；登录成功回跳到调研模块，不是回首页。
  5. 进入调研：只有一条待办就直达任务详情；多条则停在任务列表。

4.1 卡片

方案：企微素材库配一张固定卡片，CC 一键转发。 不需要开发，外观即为正规的小程序卡片。

项值
类型企微聊天里的小程序卡片
指向调研模块页（例：pages/survey/list），不是首页
参数无个人参数；最多带 source=cc 用于统计
标题本次调研名称（例：系统性红斑狼疮诊疗习惯调研）
描述约 25 分钟 · 完成即获劳务酬谢（一行内写完，超长会被截断）
缩略图品牌图，1:1，从 44px 缩略图到聊天里都能看清

卡片是通用的，所以任何人点开都能进——身份由登录决定，不由卡片决定。CC 不用为每个医生单独生成，发同一张即可。

4.1.1 上线前要配的四件事（交给企微管理员）

  1. 企微管理后台 → 应用管理 → 小程序：把「医瞳境元」小程序关联到本企业
  2. 配置素材卡片：标题、描述、缩略图、页面路径（pages/survey/list）
  3. 把这张卡放进 CC 的素材库/快捷回复，或挂到聊天工具栏
  4. 用测试号实发一次，确认点开落在调研模块而不是首页

4.1.2 这套方案的统计边界

卡片不带个人参数，所以：

  • 能统计：登录后的任务打开率、完成率、用时；
  • 不能统计：谁收到了卡片、谁点开了但没登录。

要做到"知道谁点了没填"，必须换成后台接口发送（带参数），那是下一期的事。

4.2 登录

沿用小程序现有登录页，不新造：

  • 快捷登录：微信手机号授权，一步到位（推荐主路径）
  • 验证码登录：手机号 + 短信码
  • 密码登录：已有账号的老医生

登录成功后必须回跳调研模块——回首页等于让医生再找一次，是把人往外推。

4.3 登录后落在哪

情况落点
该医生名下只有 1 条待办直接进任务详情第 1 题
多条待办任务列表
没有待办列表空态 + 「你的邀请还没到，请联系项目联系人」

5. 信息架构

三个 Tab：任务 / 消息 / 我的（沿用）。

从卡片进来、且未登录时，登录页不显示 Tab；登录后进入调研模块，Tab 恢复正常。

任务详情只有一个页面，四种状态换皮肤，不做四个页面。

6. 核心流程

A. 从卡片进入（主路径）

  1. 医生在企微里点开卡片
  2. 小程序启动 → 落在调研模块
  3. 未登录 → 登录页 → 快捷登录（手机号授权）
  4. 登录成功 → 回跳调研模块
  5. 只有一条待办 → 直接进第 1 题
  6. 一屏一题作答，自动保存 → 提交
  7. 结果：通过 → 归档可读；退回 → 只改被退回的题

B. 自己打开（次路径）

  1. 医生从微信「最近使用」或搜索打开小程序
  2. 有未完成 → 首页弹窗（规则见 7.1）
  3. 无未完成 → 首页正常展示

异常分支：未登录 / 登录过期 / 没有待办 → 见第 10 节的对应处理。

7. 关键页面

界面已定稿并有可点原型：调研模块-定稿原型.html。下列描述以原型为准。

7.1 首页入口（两级）

入口只保留两种，不再做常驻悬浮胶囊：

层级形态什么时候出现打断
L1 弹窗居中卡片，一个主行动 + 一个轻退出后台判断有未完成调研，且满足下面的频控条件强
L2 卡片会话卡里的「我的调研」入口永远在无

弹窗承担"让你现在就知道"，卡片承担"随时能找到"。中间那层常驻胶囊已移除——它既不够显眼，又长期占着页面顶部。

7.1.1 弹窗触发规则

后台返回的不是"有没有待办"一个布尔值，而是任务状态 + 上次提示时间，前端据此决定：

后台状态弹窗文案主按钮
新任务（未开始）弹你有 1 项新的调研去看看
填写中（有草稿）弹继续上次未完成的调研继续填写
待我补充（被退回）弹工作人员请你补充 2 题去补充
已提交 / 已完成不弹——

频控（必须实现，否则任务做完之前等于每次打开都弹）：

  1. 同一任务、同一自然日，最多弹一次；
  2. 用户点了「稍后再说」→ 当天不再弹，只留 L2 卡片；
  3. 任务状态再次变化（例如从"填写中"变成"待我补充"）→ 重新获得一次弹窗机会；
  4. 医生从通知/卡片直接进入任务详情时，首页不叠加弹窗；
  5. 提交成功后当次会话不再弹。

后台契约建议字段：taskId、status（new/draft/returned/submitted/done）、lastPromptedAt、pendingCount。前端用 lastPromptedAt 判当天是否已弹过，不依赖本地存储（换设备、清缓存都不能导致重复骚扰）。

7.2 授权引导

只在一处出现，且必须说清"为什么要手机号"：用于匹配你的调研任务，不用于营销。

医生拒绝授权时，给出"用调研编号查询"的手动通道，不把路堵死。

7.3 任务列表

每张卡固定四行：状态色点、项目名、「还需约 25 分钟，3 月 5 日截止」、唯一主按钮。

一屏最多 3 张卡；已完成任务折叠到列表底部。

7.4 任务详情 · 填写态

  • 顶部：项目名 + 状态 + 「已保存 12:03」
  • 说明：默认折 3 行，可展开
  • 题目：一屏一题，共 32 题，显示「模块名 · 3/32」，上一题 / 下一题；进度条按六个模块分段，可点跳转
  • 底部：没答完置灰显示"还剩 5 题"，最后一题变「提交」

没有保存按钮，停手 1 秒自动落盘。

题量与时长：32 题按六个模块组织（患者画像 5 / 诊断检查 5 / 活动判断 5 / 治疗方案 8 / 并发症 5 / 随访依从 4），完整填完约 25 分钟。小程序里允许分次填，草稿自动保存。

7.5 需补充态（折叠形态）

退回的题量通常只有 1–3 道，此时不用一屏一题，改用可折叠列表：

  • 顶部横幅说明要补几题；
  • 只展开被退回的题，其余折成"已完成"一行；
  • 工作人员的原话直接显示在被退回的题下方；
  • 改完点「重新提交」，不重走全部题目。

7.6 已归档态

按题号竖排全部题目与答案，长按可复制。底部两个按钮：保存为图片、复制全文。

不提供文件下载。

7.7 反馈

底部常驻「遇到问题」。打开是半屏表单，自动带任务号、页面、机型、时间；医生只写一句话，可选 3 张截图。

8. 状态模型

状态医生看到能做什么
待完成待完成（约 25 分钟）填写、退出、暂存
需要你补充需要你补充 2 题改答案、重新提交
已提交已交给工作人员查看、反馈
已完成可查看你的记录阅读、保存、复制

界面上不出现"待我接收""填写中""等待审核"——那是运营术语。

9. 功能需求

#功能验收标准
F0登录后直达点开卡片 → 登录 → 3 秒内落到该任务第 1 题；无待办时给明确空态，不出现白屏
F0a登录回跳登录成功回跳调研模块，不回首页
F1免登录回访绑定后 30 天内打开直达该任务，0 次输入
F1a首页弹窗仅"自己打开"路径生效：有未完成时弹一次，从卡片直达时不弹
F2任务列表首屏 ≤ 3 张卡；≤ 2 次点击进入可填写态
F3一屏一题不用滚动即可看到题干、输入框、下一题
F4自动保存停手 1 秒内落盘；杀进程重进不丢
F5提交回看可逐题跳转修改；提交幂等
F6退回补充只展开被退回的题；重提 ≤ 2 步
F7归档阅读单页可读，长按可复制
F8导出生成可保存图片；复制全文成功率高
F9反馈必填字段 ≤ 1，自动带上下文

F0 的实现约束

  • 卡片 path 指向调研模块，不带个人参数
  • 未登录时必须先登录，登录后回跳调研模块（redirect 参数带上原始落点）
  • 登录态沿用小程序现有机制，不做第二套
  • 只有 1 条待办时跳过列表直达详情；多条时停在列表

F0a 登录方式的约束

  • 快捷登录（手机号授权）必须由医生主动点击触发，不能自动调起
  • 调用前需完成小程序《用户隐私保护指引》配置并取得同意
  • 手机号快速验证按次计费，需要预算口径
  • 同一 openid 重复授权不重复建档

10. 异常与边界

场景处理
点开卡片但未登录走登录页，登录后回跳调研模块
登录后没有待办空态「你的邀请还没到，请联系项目联系人」，不显示空白
医生换微信号登录以手机号为准，能看到该手机号名下的任务
号码不在名单进待核实队列，医生可浏览说明，不显示空白
医生拒绝授权提供调研编号手输通道
一个号码对应多个项目全部列出，按截止时间排序
断网作答本地暂存，恢复自动同步，标注"待同步"
两处同时作答以服务端最后写入为准，另一处提示"内容已更新"
小程序被强杀重启回到上次位置
保存图片失败降级为"已复制全文"

11. 指标

获客漏斗（本期核心）：

环节说明
触达送达短信/公众号实际到达
H5 打开率点开说明页的比例
按钮点击率点「打开小程序」的比例
手机号授权率关键断崖，低于 60% 要回看 H5 信任说明

产品指标：

  • 打开到提交的中位时长 ↓ 30%
  • 需人工解释"怎么提交"的反馈量 ↓ 50%
  • 归档保存成功率 ≥ 99%
